# 🌐 News Headlines Scraper

A simple command-line web scraper that fetches latest news headlines
from popular RSS feeds without any external libraries.

## Features
- Scrape headlines from BBC News, Reuters, and Al Jazeera
- Display formatted headlines in the terminal
- Save headlines to a JSON file
- No external libraries needed — uses Python built-ins only

## How to Run

```bash
python main.py
```
